# barber-system

Proyecto React + Vite inspirado en la estructura de `barber-system`.

## Estructura principal

- `public/`
- `src/`
  - `assets/`
  - `components/`
  - `context/`
  - `pages/`
  - `routes/`
  - `services/`
  - `theme/`
- `package.json`
- `vite.config.js`

## Comandos

- `npm install`
- `npm run dev`
- `npm run build`
